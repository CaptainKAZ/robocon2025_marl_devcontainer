# 交叉对打：iter300（上一轮，A） vs iter450（最新，B）

单组共享 actor（role_ids [0,1,2,2]）⇒ 无法只换攻/守权重；本实验两份 policy 各前向一次、按 agent 行拼接动作。
格 = 攻方胜率 / 码1（命中）占比；X@Y = 攻方用 X、守方用 Y。

## det 口径（192 envs × 3 rounds = 576 局/格）

| 攻方 \ 守方 | A (iter300) | B (iter450) |
|---|---|---|
| **A** (上一轮) |  40.1% / 码1 15.5%  (n=576) |  20.0% / 码1  3.5%  (n=576) |
| **B** (最新) |  63.5% / 码1 36.3%  (n=576) |  34.7% / 码1 10.4%  (n=576) |

终局构成（各格 top5）：
- `A@A`：被盖×139 己方犯规×137 造犯规×128 命中×89 超时×50
- `B@B`：己方犯规×204 造犯规×135 被盖×89 超时×64 命中×60
- `A@B`：己方犯规×267 造犯规×91 超时×88 被盖×84 命中×20
- `B@A`：命中×209 造犯规×147 己方犯规×108 被盖×82 守方误伤×10

## random 口径（192 envs × 3 rounds = 576 局/格）

| 攻方 \ 守方 | A (iter300) | B (iter450) |
|---|---|---|
| **A** (上一轮) |  39.9% / 码1 18.9%  (n=576) |  19.3% / 码1  4.2%  (n=576) |
| **B** (最新) |  62.0% / 码1 37.3%  (n=576) |  34.0% / 码1 13.5%  (n=576) |

终局构成（各格 top5）：
- `A@A`：被盖×136 造犯规×110 命中×109 己方犯规×106 超时×81
- `B@B`：己方犯规×194 造犯规×113 超时×99 被盖×81 命中×78
- `A@B`：己方犯规×253 超时×132 造犯规×85 被盖×50 命中×24
- `B@A`：命中×215 造犯规×138 己方犯规×105 被盖×91 超时×15

## 读法
- 自对各格（A@A / B@B）是同一份权重自打，作为该档的基线。
- `A@B` 越低于 `A@A` ⇒ B 的防守更能遏制 A 的进攻；`B@A` 越高 ⇒ B 的进攻越能打穿 A 的防守。
- 注意：本实验里的 A 是 v41 末档（奖励改动前），B 是 v42 末档（A2 新通道 + 被盖拆分之后）；两档都只训练到各自阶段，不代表收敛上限。
